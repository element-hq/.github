## More about Element, the company

Element is the leading upstream vendor for [Matrix](http://matrix.org), the decentralised standard for real time communications. 

Element is led by the team that created Matrix, and has contributed more than 90% of key server components and SDKs to the Matrix project. Element continues to develop and maintain that majority of the Matrix open standard, under the guidance of The Matrix Foundation.

Element provides a product portfolio of Matrix clients, backend components and distributions to provide digitally sovereign communications. The majority of Element software is released under AGPLv3, with additional enterprise features available on a subscription basis.

Read more about the [relationship between Element and Matrix](https://element.io/en/matrix-relationship).

### Get Element
- For personal use, you can simply [download the Element app](https://try.element.io/get-started) and use it on a server of your choice (like the free Matrix.org public server).
- For self-hosted casual use on a small scale (easily supporting up to 100 users), [Element Server Suite Community (ESS Community)](https://element.io/en/server-suite/community) is our free-to-use self-hosted distribution.  
- For government, public sector or other professional use, we provide [Element Server Suite Pro (ESS Pro)](https://element.io/en/server-suite/pro).
